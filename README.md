Tai aparatinės įrangos ir FPGA projektas, skirtas itin trumpų optinių impulsų sklidimo laikui matuoti pikosekundžių tikslumu. Visa optika, greitaeigis lazerio siųstuvas ir fotodiodo imtuvas sumontuoti ant standaus aliuminio profilio stendo, užtikrinančio mechaninį stabilumą bei precizišką atstumų reguliavimą. Signalų formavimui suprojektuota speciali analoginė plokštė, o laiko intervalų skaitmenizavimas ir kalibracija atliekama FPGA luste išnaudojant sparčiąsias vėlinimo linijas (TDL). Tokiu būdu visa grandinė apima viską nuo nanosekundinio šviesos impulso generavimo iki paruoštų matavimo duomenų perdavimo į kompiuterį
