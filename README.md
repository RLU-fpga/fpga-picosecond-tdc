Uždarojo grįžtamojo ryšio optinė vėlinimo sekimo sistema (ODLL), skirta dviejų lazerių impulsų sinchronizavimui su pikosekundiniu (<10 ps) tikslumu. 
Projektas apima visą ciklą nuo fizinės aparatinės įrangos iki skaitmeninio apdorojimo: sparčius GaN lazerių impulsinius draiverius, aukštos įtampos APD priėmimo grandines su 8 GHz OPA855 stiprintuvais, aparatinį CARRY4 laiko-skaitmeninį keitiklį (TDC) FPGA logikoje bei galbut: PetaLinux valdymo sistema per Ethernet.
